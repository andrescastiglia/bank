# Método de verificación y mantenimiento

Línea base: **15/10/2026**, Argentina. Este archivo prescribe un método; no certifica que una norma siga igual después del corte.

## Jerarquía y localización

1. [Boletín Oficial](https://www.boletinoficial.gob.ar/) y [Normativa nacional](https://www.argentina.gob.ar/normativa): publicación, texto actualizado y modificaciones.
2. [Comunicaciones BCRA](https://www.bcra.gob.ar/buscador-de-comunicaciones/) y [ordenamiento y resúmenes](https://www.bcra.gob.ar/ordenamiento-y-resumenes/): regulación sectorial y textos ordenados. Usar también las instrucciones operativas del régimen informativo o sistema específico.
3. [UIF](https://www.argentina.gob.ar/uif), [AAIP](https://www.argentina.gob.ar/aaip), [ARCA](https://www.arca.gob.ar/), [COMARB](https://www.ca.gov.ar/), [CNV](https://www.argentina.gob.ar/cnv), según actividad.
4. Catálogos y documentos oficiales de ISO, PCI SSC, NIST, OWASP, SWIFT, ISACA, AICPA y BIS para estándares o compromisos de industria.

Las noticias oficiales orientan, pero no reemplazan el texto y sus anexos. Las fuentes de proveedores acreditan declaraciones comerciales y casos anunciados; no acreditan por sí solas conformidad normativa. Un blog sirve para descubrir una fuente, no para fijar la obligación final.

## Ficha de fuente

Registrar `source_id`, autoridad, tipo, número/edición, título, URL exacta, sección, fecha de publicación, fecha de vigencia, transición, fecha de consulta, sujetos, modificación/derogación y estado de lectura. Archivar el documento si está autorizado, su hash y la versión; un PDF de URL estable puede ser reemplazado.

Si el texto ordenado se actualizó después del corte histórico, reconstruir con comunicaciones de ese período y señalar el límite. No mezclar publicaciones futuras con una evaluación histórica. La fecha de indexación de un buscador no es la fecha de la norma.

## Actualización

Al inicio de una evaluación y antes de una salida a producción, revisar cambios desde el corte. En un producto operativo, asignar seguimiento a un responsable y definir una frecuencia acorde con cambios y criticidad; este skill no crea automatizaciones por sí solo. Para cada modificación, analizar sujetos, productos, datos, parámetros, contratos, reportes, pruebas, transición y evidencia de adopción. Guardar historial: no reescribir operaciones antiguas con la regla nueva.

## Alcance de las afirmaciones

Una familia relevada no demuestra cobertura de todas las circulares ni de todas las actividades del cliente. No usar la palabra «exhaustivo» como garantía universal. Mantener un registro explícito de productos sin evaluar, anexos no leídos, fuentes inaccesibles y decisiones de interpretación. Una norma voluntaria puede convertirse en obligación contractual: citar el contrato que produce ese cambio.

La certificación de un sistema de gestión cubre su alcance declarado; la conformidad de software, la autorización de una entidad y el resultado de una auditoría son objetos diferentes.
