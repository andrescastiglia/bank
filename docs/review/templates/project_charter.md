# Charter del primer producto y cliente

**Plantilla sin completar. No acredita aceptación, contratación o habilitación.** Registrar versión, fecha, proponente y responsables de decidir; enlazar evidencia cuando exista. No incluir datos de clientes/personas innecesarios.

| Campo | Valor a completar y evidencia |
|---|---|
| Problema y comprador | Segmento, entidad/rol, usuario operativo, decisor económico y dolor cuantificado |
| Oferta | Resultado por el que pagaría, modalidad de entrega/soporte y alternativa actual |
| Ruta elegida | Crédito, pagos u otro alcance delimitado; motivo y evidencia frente a alternativas |
| Incluido | Flujos, módulos/FR, datos, monedas, canales, reportes, interfaces y responsabilidades |
| Excluido/condicional | Capacidades sin promesa comercial; activador y requisitos para incorporarlas |
| Perímetro | Proveedor, entidad regulada, custodio, clientes del servicio, autorizaciones/contratos y países |
| Autoridad | Dueño de contrato/saldo, transición desde legado y quién resuelve ambigüedades |
| Condiciones comerciales | Diagnóstico/piloto/implantación/suscripción; unidad facturable, mínimo, aceptación y salida |
| Economía | Modelo de caja/costos por cohorte; financiación y datos que faltan |
| Calidad/seguridad | Criterios NFR, oráculos, amenazas, privacidad, soporte y evidencia exigida por el perfil |
| Equipo | Responsable y suplente por función, capacidad disponible e incompatibilidades |
| Contrapartes | Integraciones, responsable, contrato, sandbox, prueba, plazo y contingencia |
| Hito actual | G0/G1/G2/G3/G4, evidencia disponible y condición de avance |
| Decisiones abiertas | Pregunta, alternativas, responsable, dependencia y próxima acción |
| Criterio de detener/reducir | Falta de demanda, margen/caja insuficiente, integración inviable o control sin resolver |

## Primer incremento verificable

Elegir un circuito de negocio completo con datos sintéticos: alta/contrato, comando financiero, asiento, conciliación y salida documental/regulatoria pertinente. Registrar excepciones, doble intervención, fallos y resultado esperado. El incremento no reemplaza las condiciones del perfil para operar datos/fondos reales.

## Registro de decisiones

| ID | Pregunta y alternativas | Evidencia | Responsable de decisión | Estado y fundamento | Impacto/acción |
|---|---|---|---|---|---|

No prellenar decisiones como aprobadas. Un responsable sugerido no es una persona designada ni disponible. La revisión de un prototipo no es aceptación contractual o institucional del piloto.
